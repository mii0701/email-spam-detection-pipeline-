# Email Spam Detection Machine Learning Pipeline

## Overview & Purpose
This project is an end-to-end Python machine learning pipeline designed to clean raw, unstructured text data and accurately predict whether an incoming email message is spam or safe.

## Problem Addressed
Messy, unstructured text data often contains noise, missing values, and irrelevant formatting that hinder machine learning models. This project automates the data cleaning, feature extraction, and classification workflow.

## Technologies Used
- Python
- Pandas, NumPy, Scikit-learn
- Visual Studio Code / Jupyter Notebook

## Key Features
- Automated data hygiene and missing value imputation
- Text pre-processing (noise removal and tokenization)
- Machine learning classification model training and evaluation
- Automated spam prediction on unseen text inputs

## How to Run
1. Clone the repository: `git clone https://github.com/[your-username]/email-spam-detection-pipeline.git`
2. Install required dependencies: `pip install -r requirements.txt`
3. Run the main script: `python spam_detector.py`

## Key Learnings
- Efficient feature extraction techniques for text pre-processing.
- Managing data cleaning pipelines to ensure model input consistency.
- Evaluating classification metrics (Precision, Recall, F1-Score) to prevent false positives.
